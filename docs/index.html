Household platform

家庭综合平台

A private system for one household.

面向家庭内部使用：微服务后端、管理端、移动端和两个微信小程序共用业务接口，并按家庭与客户端范围授权。

壹

它做什么

仓库版本 0.1.0-SNAPSHOT。这是给一个家庭用的系统，不是对外开放的社交网络。

后端按服务拆开，各自持有自己的数据，由网关做统一入口。家庭归属取自已经校验过的会话，不信任客户端自己申报的家庭标识。管理端顶栏写着「把时间，留给家人」。

同一套接口同时给管理端、移动端和两个微信小程序使用。客户端不同，能碰到的范围也不同：例如档案小程序只做登录和档案，管理端则面向家庭管理员。

源码、设计笔记和持续集成都在公开仓库 wangBoYi972/family-platform。本页只转述仓库里已经写明的结构，不代替部署文档。

贰

后端服务

这些服务都在 backend/。旁边还有公共模块 family-common、family-security、family-messaging 和 family-api。

01

统一入口

family-gateway

API 入口、路由、跨域，以及 JWT 前置校验。网关本身不存放业务表。

02

成员与登录

family-user-svc

成员白名单、登录、会话校验、注销、家庭关系和角色权限。注册需要管理员发放的邀请码。

03

家庭内容

family-content-svc

相册、动态、日历、任务和公告。列表可以按关键字或状态检索，并支持分页。

04

文件

family-file-svc

私有文件的上传、下载授权和资源元数据。存储有本地实现，也有可插拔的 S3 兼容适配器。

05

档案

family-archive-svc

家庭档案、健康记录和访问审计。管理员可以查看近一段时间的访问汇总。用药计划与复诊也在这个服务里：药名等内容加密保存，设为仅本人时其他成员和管理员都看不到。家庭端和移动端当天会提醒一次未服用的药和当天的复诊。微信订阅模板还没接上，不会因此发出订阅消息。

06

消息

family-im-svc

会话、消息、已读和 WebSocket。文本、图片、语音和文件都有对应类型；私聊只投递给会话双方。

07

实时通话

family-media-svc

通话状态、WebSocket 信令、TURN 时效凭据和通话记录。媒体走 WebRTC。仓库里实现了一对一，以及最多 8 人的家庭通话。

08

家庭小助手

family-ai-svc

对话助手，用当前用户自己的令牌查询本家庭的任务、日程和纪念日，并搜索动态、相册、公告、档案与文件。未配置模型时关闭。历史按用户和家庭保存，不写入即时消息库。

09

家居设备

family-iot-svc

家庭成员可以绑定 Home Assistant 中枢，每家一条。地址只接受本机和私网，公网地址会被拒绝。访问令牌加密后保存，接口不回传令牌，也不回传中枢地址。绑定后按区域同步灯、开关、传感器和场景；控制只开放开灯、关灯、开关和触发场景，结果写入命令日志。没有真实中枢时可以用内置演示设备，命令只改本地快照、不向外发请求。接到真实中枢后，后续状态变化还不会写回快照：仓库里的 WebSocket 监听没有从绑定或启动流程接上，页面定时重读的仍是这份快照。

10

家庭账本

family-ledger-svc

记录支出和收入，金额用整数分。分类固定为餐饮、日用、住房、交通、医疗、教育、其他。支出要写垫付人和分摊，分摊合计必须等于这笔账；收入记在收款人名下、不分摊。本月收支和每位成员的净额由服务端按整月计算，不按当前页加总。列表可按月份、分类、垫付人或关键字分页。改删只限记账人或管理员。家庭编号只取已校验会话。

叁

四个客户端

都在 apps/。家庭端和移动端的面板、通话组件尽量只保留一份，放在共享目录里。

apps/admin-web

管理端

Vue 3、Element Plus、Vite。登录之后是任务工作台、家庭成员、家庭档案、公告通知、家庭日历，以及 AI 家庭助手设置。成员页可以管理账号、密码和注册邀请码。

apps/mini-family

家庭综合小程序

uni-app（Vue 3）。页面是首页、日历、任务、账本、聊天、家庭圈、家居和我的家（成员、公告、档案、用药复诊、文件、设置），与移动端共用共享面板。

apps/mini-archive

档案小程序

同样基于 uni-app，使用独立的档案客户端身份。范围收在登录和档案列表，不承担家庭端的全部功能。

apps/mobile-app

移动端

uni-app 壳。七个分组：任务、账本、日程（日历与纪念日）、家庭圈（动态、相册、时光轴）、消息、家居、我的家（公告、文件、档案、用药复诊、成员、设置）。顶栏有全局搜索，并接入通话和实时刷新。

apps/shared

跨端共享

通话组件、任务 / 日历 / 动态 / 相册 / 公告 / 文件 / 档案 / 成员 / 聊天 / 账本 / 家居 / 用药复诊等面板、分页、实时通道和请求错误文案。改一处，家庭端与移动端一起生效。管理端是另一套 Vue 应用，不走这套 uni-app 面板，目前也没有账本和家居入口。

肆

已经落在代码里的能力

下面这些都能在当前仓库的服务或客户端里找到，不是路线图上的空标题。

  • 进入家庭白名单与邀请码注册，角色区分管理员和成员。密码只保存 BCrypt 哈希。每个家庭最多十位启用成员。
  • 过日子任务可指派、开始、完成；日历和纪念日、动态、相册、公告都按家庭存放。相册时光轴可以导出一份单文件 HTML 纪念册。
  • 文件与档案文件下载需要授权。档案有访问记录；管理端用纯样式画出近 30 天的访问概览。用药计划与复诊放在同一服务里，正文加密，可设为仅本人可见。
  • 记账支出和收入按整数分记账。分类是餐饮、日用、住房、交通、医疗、教育、其他。支出要指定垫付人和分摊，合计必须等于这笔账；收入不分摊。本月收支和每人净额由服务端按整月计算。改删只限记账人或管理员。
  • 家居家庭成员可以绑定 Home Assistant 中枢。地址只接受本机和私网，令牌加密保存，接口不回传令牌和中枢地址。同步灯、开关、传感器和场景；控制只开放开灯、关灯、开关和触发场景。没有真实中枢时可用内置演示设备。真实中枢的后续状态还不会写回快照。
  • 说话消息支持文本、图片、语音和文件。新消息走实时帧，断线时退回轮询。已读回执会推送。自己发出的消息可在两分钟内撤回，界面留一句「此消息已撤回」。
  • 见面一对一和最多 8 人的家庭通话。信令在服务端，音视频走 WebRTC。超过 8 人所需的 SFU 仍在上线验收里，还没有当作完成项。
  • 问家里的事家庭小助手只查询这个用户原本就能看到的数据。回答以流式输出。微信订阅消息同样是：没配凭证就自动关闭，不假装已经接通。

技术栈

版本取自仓库的 Maven 与前端清单，随代码更新，不在这里另造一套。

语言与运行时
Java 21。构建用 Maven，强制 Java 21。
服务框架
Spring Boot 3.3.5，Spring Cloud 2023.0.3，Spring Cloud Alibaba 2023.0.3.2。注册与发现使用 Nacos。
数据
MyBatis-Plus 3.5.17，Flyway 迁移。本地开发用各自的 H2；生产配置面向 MySQL。密钥和数据库口令从环境变量读取，不写在这个页面上。
消息与实时
Redis、RabbitMQ、WebSocket。领域事件经 Outbox 再通知在线客户端。通话媒体是 WebRTC。
接口与观测
springdoc OpenAPI 2.6.0，本地可开 Swagger，生产默认关闭。请求带 X-Request-Id。生产环境暴露 health、info、prometheus。infra/ 里有 Prometheus 与 Grafana 的编排。
前端
管理端：Vue 3、Element Plus、Vite。小程序与移动端：uni-app（Vue 3）。持续集成使用 Node.js 20 与 pnpm 9 构建管理端。
工程化
GitHub Actions 跑后端校验、管理端构建和依赖扫描。网关、成员、内容、文件、档案、消息、通话和家庭小助手这八个服务有多阶段、非 root 的 Dockerfile。infra/docker-compose.yml 编排 MySQL、Nacos、Redis 以及这八个服务。家居和账本已在 Maven 模块和网关路由里，编排文件和 Prometheus 抓取名单还没有它们。
仓库地图
backend/ 服务，apps/ 客户端，infra/ 编排与监控，docs/ 设计笔记和本页，scripts/ 通话冒烟脚本。

现在到哪一步

README 把「代码里的基础闭环」和「正式上线前还要验收的事」分开写了。这里保持同样的说法。

仓库里已经有的

  • 网关路由与 JWT 前置校验，用户服务的登录、会话和成员管理。
  • 内容、文件、档案、消息、通话、家庭小助手、家居和账本各自的数据表与迁移。
  • 管理端接到成员、任务、公告、日历、档案和助手设置。账本和家居还没有管理端入口。
  • 家庭端与移动端共用面板，账本和家居已接到这两个端；实时刷新、聊天推送和通话信令有对应实现。
  • 链路追踪、结构化日志、OpenAPI、容器镜像和持续集成配置已经放进仓库。

还不能写成已完成

  • MySQL 与 Nacos 实例联调。
  • 真实短信或微信身份认证。
  • 对象存储在真实环境中的验收。
  • 公网 TURN 的实网穿透与压测，以及 8 人以上所需的 SFU。
  • 两个小程序的真机回归。
  • 监控告警，以及备份恢复演练。

English

family-platform is a household-scoped system: a Spring Cloud Alibaba backend, an admin console, a mobile client, and two WeChat mini programs. They share APIs and authorize by family and client. It is not a public social network.

The backend services are the gateway, members, content, files, archives, messaging, calls, an optional family assistant that stays off until a model is configured, home devices, and a family ledger. Home devices bind to Home Assistant, or to a built-in demo hub that does not call the network. The ledger records income and shared expenses in integer cents, and the monthly totals are computed on the server. These two services are in the Maven modules and gateway routes. The container compose file and the Prometheus scrape list do not include them yet. Source and notes live in the public repository.
