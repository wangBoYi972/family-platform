# 产品完善与验收记录

日期：2026-09-29。

## 产品判断与本轮范围

平台已有服务划分和基础接口，但家庭成员的日常操作仍存在断点。本轮优先解决移动端不能处理任务、管理端按钮与状态规则冲突、日历不能完整查看或修订的问题，同时承接引用会话的要求，显式使用 @Autowired 注入。

## 已完成

| 模块 | 原有缺口 | 本轮结果 |
| --- | --- | --- |
| APP 任务 | 只能浏览，不能创建或处理 | 增加创建、负责人选择、截止日期、开始、完成、搜索及状态和逾期筛选 |
| APP 权限与反馈 | 缺少操作权限提示和失败处理 | 按会话展示处理入口；最终由服务端鉴权；增加错误提示、刷新和提交期间防连点 |
| 管理端任务 | 待开始任务能点击完成，但服务端拒绝 | 按待开始、进行中、已完成提供按钮；增加防连点、搜索筛选、本地日期判断和窄屏导航 |
| 责任人文案 | 未指派显示为全家，实际其他普通成员无权处理 | 明确未指派任务由创建者跟进 |
| 日历 | 不展示日期，只能新建 | 日期与每年纪念标记、新建、完整正文、编辑回填、删除确认及取消删除 |
| 公告和档案 | 列表正文截断 | 公告支持详情、编辑、删除和置顶开关；档案详情调用原授权接口，保留访问审计 |
| 移动端 H5 | 构建通过但页面空白 | 补充直接依赖 @dcloudio/uni-h5，运行时与编译器统一为 3.0.0-5020620260917001，移除替代平台 Vue 的别名 |
| 后端注入 | 隐式单构造器注入 | 30 个 Spring 类显式使用 @Autowired：20 个类改为字段注入，10 个类保留构造器并添加注解 |

保留构造器的范围包括安全和存储初始化、配置校验、映射表构建及部分原有组件。未将密钥、普通值对象或手动创建的内部类错误地改为容器依赖；原有事务和权限规则不变。

## 已知限制与后续优先级

| 优先级 | 待办 | 当前边界与验收要求 |
| --- | --- | --- |
| P0 | 正式部署验收 | MySQL、Nacos、HTTPS、密钥注入和备份恢复需真实环境验证，H2 不替代生产验收 |
| P1 | 多端发布 | 本轮实测管理端与 APP 的 H5；Android 安装包和两个微信小程序仍需真机、授权及发布验收 |
| P1 | 家庭提醒 | 每年纪念仅保存和展示标记，尚无定时提醒或系统推送，需要明确渠道、时间和订阅授权 |
| P1 | 其他界面验证 | 公告置顶和档案详情已接通接口并通过构建；本轮未启动档案服务验证新增详情页面的端到端流程 |
| P1 | 媒体及对象存储 | 现有代码不代表真实 S3、SFU/TURN、音视频通话完成，仍需部署和设备联调 |
| P2 | 长期数据检索 | 任务筛选作用于接口返回的最近 500 条；完整历史检索需要后端分页或游标 |
| P2 | 构建治理 | 管理端有大包提示；移动端安装有 @dcloudio/types 的 3.4.31/3.4.32 peer 差异提示，未升级无关依赖 |

本记录区分已实现、已实测和待生产验收事项，不将本轮补齐描述为整个系统已经正式上线。
