# 客户端开发说明

## 客户端目录

- `apps/admin-web`：Vue3 + Element Plus 管理端。
- `apps/mini-family`：家庭综合小程序，使用 uni-app Vue3。
- `apps/mini-archive`：档案小程序，使用 archive client 身份。
- `apps/mobile-app`：移动端共享壳，当前复用家庭端组件结构。

## 本地运行

在客户端目录执行：

```powershell
pnpm install
$env:VITE_API_BASE_URL="http://127.0.0.1:8080/api"
pnpm dev:h5
```

微信开发者工具或 Android 真机使用 uni-app 官方运行方式打开对应目录。正式客户端使用手机号和密码登录，不保存密码，只保存短期访问令牌。测试验证码仅在后端 `local` profile 开启，不能用于生产。`r`n`r`n管理员首次初始化后通过管理端“账号与家庭成员”创建成员账号和设置密码。成员修改密码后旧设备必须重新登录；停用成员会立即阻断已有令牌的访问。

## 身份边界

家庭端登录 client 为 `family`，档案端登录 client 为 `archive`。服务端会校验 JWT、会话、家庭成员资格和请求方法；客户端不提交 householdId 作为可信权限依据。

## 当前已接入

- 家庭端：登录、任务列表、动态列表、公告入口、退出。
- 档案端：登录、档案列表、家庭权限返回。
- 管理端：成员、任务、公告、日历、档案页面和新建表单。
- 未完成真机验收：微信登录、Android 原生音视频、SFU/TURN、推送和离线缓存。
