# 企业级工程化交付记录

日期：2026-09-28。

## 一、目标

按企业级标准对 `family-platform` 做严格代码审计与工程化加固，覆盖：安全审计、可观测性、API 文档、依赖治理、CI/CD 与容器化，并以全量构建 + 测试作为验收证据。

## 二、代码严格审计结论（逐服务）

审计范围：`family-security`、`family-common`、`family-api` 与全部 6 个业务服务（user/content/file/archive/im/media）+ gateway。以下控制在审计中逐项核对，未发现需返工的缺陷，代码基线已达到较高企业级水准：

| 面 | 已核验的控制 |
| --- | --- |
| 认证 | JWT HMAC-SHA256 强制验签，校验 issuer/过期/会话 id；BCrypt cost 12；口令 12–64 字符且 UTF-8 ≤72 字节；账号枚举用 dummyHash 恒时比较 |
| 会话 | 登录/改密以数据库行锁串行化；改密与旧会话撤销同事务；服务端注销与白名单校验 |
| 越权防护 | 家庭归属一律取自已校验会话，不信任客户端传入；readable/visible/own 三层过滤；跨家庭文件引用被文件服务按 household+visibility 拒绝 |
| 档案 | AES-GCM + AAD（家庭:档案 id）绑定密文与归属；32 字节密钥启动 fail-fast；完整访问审计（READ/CREATE/UPDATE/DELETE） |
| 幂等 | 消息以 发送者+clientId 唯一键幂等；会话/会话已读游标幂等；任务状态用乐观条件并发控制 |
| 入参校验 | 全部 DTO 声明校验（手机号/角色/枚举/长度）；口令类 DTO 覆写 toString 防日志泄露 |
| 文件安全 | 扩展名白名单、20MB 上限、UUID 存储防路径穿越、下载 `nosniff`+`no-store`+附件头 |
| WebSocket | 30 秒一次性 ticket、家庭绑定、origin 白名单 |
| 纵深防御 | Gateway 粗粒度验签 + 服务端全量复核；生产密钥 fail-fast；`local` 与 `prod` 互斥、测试验证码仅限 local |

## 三、本轮工程化加固（新增）

1. **链路追踪与结构化日志**
   - `family-security/trace/TraceIdFilter`：生成/透传 `X-Request-Id`（MDC `traceId`），记录方法/路径/状态/耗时，敏感头不落日志，finally 清理 MDC。
   - `FeignTraceConfiguration`：Feign 出站请求透传 traceId，跨服务可串联。
   - 各服务 `logback-spring.xml`：`prod` 输出结构化 JSON（logstash encoder，含 app/traceId），开发环境控制台含 traceId。
2. **API 文档**：springdoc 接入全部服务；`family-security/config/OpenApiConfig` 统一声明 Bearer 安全方案。`local` 启用 `/swagger-ui`，`prod` 默认关闭（`FAMILY_DOCS_ENABLED=true` 显式开启）。
3. **可观测端点收敛**：`prod` 仅暴露 `actuator/health,info`（实测启动日志确认为 2 个端点）。
4. **依赖治理**：根 pom 启用 maven-enforcer（Java 21、封禁 `log4j` 1.x、`log4j-core`、`commons-beanutils`）；`-Pscan` profile 运行 OWASP dependency-check（CVSS≥7 失败，结果供 CI 人工核验）。
5. **CI/CD**：`.github/workflows/ci.yml`（后端 `mvn verify` + 管理端 `pnpm build` + 依赖扫描，产物上传 artifact）。
6. **容器化**：`infra/docker-compose.yml` 扩展为 MySQL+Nacos+Redis+全部服务；各服务提供多阶段、非 root 运行 Dockerfile；MySQL init 增加最小权限业务账号 `family_app`（密码由 `MYSQL_APP_PASSWORD` 注入）；新增 `.dockerignore`、`infra/.env.example`。
7. **前端体积**：管理端 vendor 拆分（vue/element-plus 独立 chunk），应用主包降至约 21KB。

# 第三轮交付记录（2026-09-28 续）

## 十、本轮范围

将 `apps/mini-family` 从「单页只读」升级为对齐后端契约的多能力家庭客户端（任务/动态/相册/公告/成员），并完成网关 E2E 冒烟：

1. **请求层重构** `src/utils/request.js`：统一 `request`（自动附带 Bearer token、401 清会话、`ApiResponse{code,message,data}` 解包）、`upload`（`uni.uploadFile`，字段名 `file` + formData `visibility`）、`loadImageUrl`（`uni.downloadFile` 带 Bearer 后转 `file://` 供 image 展示）、`taskStatusLabel`/`roleLabel`。
2. **五个面板组件**：`TaskPanel`（创建任务：标题必填 ≤80、截止日期 picker、负责人下拉取 `/users/members`；状态推进 TODO→IN_PROGRESS→COMPLETED）、`DynamicsPanel`（发布动态：标题+正文 ≤10000、最多 9 图先传 `/files` 再以逗号 fileIds 关联 `/dynamics`；列表懒加载图片 URL）、`AlbumsPanel`（三列网格 + 预览）、`NoticesPanel`（公告列表 + 置顶标记）、`MembersPanel`（成员卡片 + 角色标签）。
3. **工作台重写** `pages/index/index.vue`：登录（口令，client=family）/退出/改密（12–64 位一致校验，成功后重新登录）三态 + 五 Tab 切换；token 持久化 `family_access_token`。
4. **契约纠偏（本轮实测发现）**：成员列表真实路径为 `/api/users/members`（`MemberController @RequestMapping("/api")` + `@GetMapping("/users/members")`），非 `/api/members`；前端按真实契约修正，网关路由无此路径、**不加死路由**（曾临时添加的 `/api/members/**` 已回退，prod/local 两份配置一致）。
5. **本地开发打通口令登录**：`LocalBootstrap` 扩展为本地管理员种子口令凭据（`user_credential` + BCrypt；默认手机 `19900000001` / 口令 `local-admin-123456`，可被 `FAMILY_LOCAL_ADMIN_PHONE` / `FAMILY_LOCAL_ADMIN_PASSWORD` 覆盖）——此前 local 仅支持 mock 验证码，三个客户端的口令登录全部被卡住；此改动同时解锁管理端与两个小程序的本地口令联调。
