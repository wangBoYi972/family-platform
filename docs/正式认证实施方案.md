# 正式认证实施方案

日期：2026-09-27。

## 目标与验收

将当前仅支持 local 验证码的登录链路扩展为真实的白名单账号密码认证，完成管理员初始化、成员密码设置、本人改密、会话撤销和四端登录接入。保留家庭与客户端权限边界，不开放公众注册。

正式短信和微信身份平台尚未配置，本轮先提供可独立部署的账号密码认证，不以固定验证码替代真实身份验证。密码仅保存 BCrypt 哈希；失败次数及锁定时间落入用户服务数据库，多实例共享。登录失败计数必须在拒绝请求后仍然提交。

初始化须显式启用并提供家庭名称、管理员手机号和密码，只允许空业务库首次执行。重启不得覆盖管理员密码。密码设置与更改必须校验归属，撤销该用户的全部历史会话。JWT 与数据库会话采用同一个到期时间。

## 本轮边界

保持现有 Spring Boot、MyBatis-Plus、Flyway 和独立数据库结构。验证范围包括真实 Spring HTTP 处理链、数据库事务、迁移、并发与前端构建。H2 自动化通过只代表开发回归通过；MySQL、Nacos、HTTPS、短信、微信、文件存储、音视频和真机发布须分别保留正式环境验收记录。

## 执行顺序

1. 新增凭据和初始化迁移，完成正式登录及持久化防护。
2. 实现管理员初始化、成员设置密码、本人改密和会话撤销。
3. 管理端、Android 客户端和两个小程序接入真实认证。
4. 执行安全回归、构建与接口验证，更新部署操作及验收证据。
