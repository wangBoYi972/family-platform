# 本地初始化与登录验证

## 前置条件

1. 运行 `infra/docker-compose.yml` 中的 Nacos、MySQL 和 Redis。
2. 创建数据库用户 `family_app`，并通过环境变量设置 `FAMILY_DB_PASSWORD`。
3. 使用至少 32 字节的随机值设置 `FAMILY_JWT_SECRET`。
4. 仅在开发环境设置 `FAMILY_AUTH_MOCK_CODE`，并显式开启 `family.auth.mock-login-enabled`。

## 初始化首位管理员

Flyway 创建表后，在受控环境中执行以下 SQL，并将手机号替换为实际家庭管理员号码：

```sql
INSERT INTO family_household (name) VALUES ('我的家庭');
INSERT INTO family_white_list (phone, household_id, role, enabled)
VALUES ('实际管理员手机号', 1, 'ADMIN', TRUE);
```

不要在 Git、配置文件、日志或接口响应中保存数据库密码和 JWT 密钥。

## 开放注册与邀请码

注册接口 `POST /api/auth/register` 对所有人开放（网关与服务端都放行了匿名访问），
但**必须填写管理员发放的邀请码**，校验不通过一律返回 403 且不会创建任何账号或凭据。

| 环节 | 说明 |
| --- | --- |
| 发放 | 管理员在「账号与家庭成员 → 注册邀请码」生成，可指定角色（成员/管理员）、可注册人数（1–10）、有效期（1–720 小时） |
| 形态 | 明文形如 `FAM-7K2M-QX4P`，去掉了 0/O/1/I；**只在生成接口返回一次**，库里只存 SHA-256 摘要与尾号 |
| 校验 | 不存在 / 已作废 / 已过期 / 已用尽 → 拒绝；管理端注册只接受管理员邀请码，成员邀请码需在小程序端使用 |
| 归属 | 加入哪个家庭、拿到什么角色由邀请码决定，注册人无法自选；仍受「每户最多十位启用成员」限制 |
| 限流 | 同一手机号 10 分钟内最多 5 次注册尝试，超出返回 429 |

管理员接口（需 ADMIN 令牌）：`GET /api/users/invite-codes`、`POST /api/users/invite-codes`、
`DELETE /api/users/invite-codes/{id}`（作废）。列表只回显尾号，不返回明文。

## 本地最小启动集

H5 首页会并发请求多个服务，**少启一个就会在页面上显示「请求失败」**，所以本地至少要起四个：

| 服务 | 端口 | 缺了会怎样 |
| --- | --- | --- |
| `family-gateway` | 8080 | 前端所有 `/api/**` 都连不上 |
| `family-user-svc` | 8081 | 登录失败，成员列表为空；其他服务校验会话也会跟着 503 |
| `family-content-svc` | 8082 | 首页「任务 / 日历 / 动态」三块同时报「请求失败」 |
| `family-archive-svc` | 8088 | 「加密档案」页报「服务暂时不可用」（网关拿不到 8088 实例） |
| `family-im-svc` | 8089 | 聊天页左侧会话列表与消息全部报「请求失败」 |
| `family-media-svc` | 8090 | 通话入口拨号即失败（信令与 TURN 凭据都在这里） |

启动顺序没有强依赖，但网关最后起可以少几条连接拒绝日志。统一用 JDK 21 启动：

```bash
cd backend
java_home=$JAVA_HOME            # 必须是 21，默认 java 可能是 17
for svc in user content archive im media gateway; do
  env -u SERVER__PORT SPRING_PROFILES_ACTIVE=local \
    FAMILY_JWT_SECRET=local-development-secret-32-characters-min \
    "$java_home/bin/java" -jar family-$svc-svc/target/family-$svc-svc-0.1.0-SNAPSHOT.jar \
    > /tmp/svc-$svc.log 2>&1 &
done
```

三个必须注意的点：

- 宿主若注入了 `SERVER__PORT`，会覆盖 `server.port`（表现是服务起在随机端口、网关 503），启动前用 `env -u SERVER__PORT` 清掉；
- 本地库是 `backend/.local/*.mv.db` 的 H2 文件，Flyway 迁移失败会留下失败记录并阻止下次启动，确认是空库时直接删掉对应的 `.mv.db` 重跑即可；
- `family-archive-svc` 的 AES 密钥由 `application-local.yml` 的 `family.archive.key` 提供（缺省读 `FAMILY_ARCHIVE_KEY` 环境变量，本地有固定开发值）。密钥缺失会让该服务启动即失败，日志末尾是 `FAMILY_ARCHIVE_KEY 必须为 32 字节随机密钥的 Base64 编码`；本地这个值一旦用于录入档案就不要改，否则历史档案解密会返回 410。
