# 微服务实施规划

## 服务边界

| 服务 | 数据归属与职责 |
| --- | --- |
| family-gateway | 统一入口、鉴权、限流、路由，无业务数据表。 |
| family-user-svc | 用户、白名单、成员关系、角色与 JWT。 |
| family-content-svc | 相册、动态、日历、任务、公告。 |
| family-file-svc | 私有对象、上传与下载授权。 |
| family-archive-svc | 档案、健康记录和访问审计。 |
| family-im-svc | 会话、消息、已读和 WebSocket 信令。 |
| family-media-svc | 通话状态机·信令·鉴权·录音；SFU 由独立 livekit-server 承载（2026-11-24 定案 LiveKit 自建，20+ 人），TURN 对接现有 coturn。改造方案见 `docs/LiveKit-SFU改造方案.md`。 |

## 迭代顺序

1. 基础设施、Gateway、用户服务、白名单登录、JWT。✅
2. 家庭关系和角色权限，确保所有业务表按家庭隔离。✅
3. 内容、文件和档案服务，并对档案建立审计与私有访问控制。✅
4. 文本、图片和语音消息。✅
5. Android 音视频、独立 SFU 与 TURN 压测。SFU 选型已定 LiveKit 自建（2026-11-24），改造方案见 `docs/LiveKit-SFU改造方案.md`，待实施与压测验收。

## 工程化进度（2026-09-28）

- Gateway 限流：已实现（Redis 令牌桶，按用户/IP，条件启用）——规划中 Gateway 职责「限流」落地。
- file-svc 对象存储：已实现可插拔抽象（local / S3 兼容适配器）——规划中「私有对象」能力落地。
- 监控：Prometheus + Grafana 已接入 compose；备份/恢复脚本已交付（待真实实例演练）。
